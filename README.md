# laiarodrigo.github.io

Static GitHub Pages site scaffold for a personal academic website.

## Files

- `index.html`: about page
- `publications.html`: publications page
- `cv.html`: CV page
- `assets/css/site.css`: shared styles
- `assets/js/site-data.js`: all placeholder content in one place
- `assets/js/main.js`: renders shared profile info and page content
- `assets/images/profile-placeholder.svg`: default avatar until you provide a real image

## Replace These Placeholders

Edit `assets/js/site-data.js` to replace:

- name and title
- profile photo path
- location, affiliation, email
- website and social links
- about text
- publication entries
- CV sections
